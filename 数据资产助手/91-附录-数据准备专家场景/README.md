# 91 附录 数据准备专家场景

本目录用于存放“数据准备专家”相关方案、设计、架构和原型材料。

在数据资产助手方案中，数据准备专家作为一个典型应用场景沉淀，主要对应“数据源登记 / 数据准备 / 元数据采集 / 数据地图更新 / 空间项目绑定”的长流程编排。

汇报主线中不单独展开本目录内容，只在需要说明“数据资产助手如何落地到具体业务场景”时作为附录引用。

## 场景定位

| 项目 | 说明 |
| --- | --- |
| 所属助手 | 数据资产助手 |
| 对应子能力 | 数据源 SubAgent、元数据采集、数据地图、空间项目绑定、流程状态跟踪 |
| 典型入口 | 用户通过自然语言发起“登记数据源”“准备一个 MySQL 数据源”“同时登记 PRD/UAT 数据源”等诉求 |
| 复用能力 | 现有数据源登记页面、审批流程、元数据采集、数据地图更新、空间项目绑定流程 |
| 新增能力 | 自然语言识别、流程编排、状态跟踪、异常引导、结果解释 |
| 汇报位置 | 附录案例，不放入主线架构汇报 |

## 文件说明

- `data_prepare_expert_requirement_draft.md`：需求草稿。
- `data_prepare_expert_requirement.md`：需求文档。
- `data_prepare_expert_design.md`：产品或方案设计文档。
- `data_prepare_expert_architecture.md`：架构设计文档。
- `data_prepare_expert_technical_design.md`：技术设计文档。
- `data_prepare_expert_prototype.html`：交互原型或页面原型。
