# 架构设计

本目录用于集中存放数据资产助手的详细架构设计材料。

主汇报链路中只保留 `03-数据资产助手应用架构设计`，用于说明数据资产助手的应用模块和能力分层。技术架构、部署架构、数据架构作为展开材料统一放在本目录，避免主线架构图过载。

## 文件说明

| 文件 | 关注点 |
| --- | --- |
| `01-数据资产助手技术架构设计.md` | FastAPI、LangGraph、LangChain Core、Tool Adapter、可观测等技术组件如何协作 |
| `01-数据资产助手技术架构图.drawio` | 技术架构正式评审图 |
| `02-数据资产助手数据架构设计.md` | 助手侧数据模型、表结构、会话、任务、记忆、确认、审计关系 |
| `02-数据资产助手数据架构图.drawio` | 数据架构正式评审图 |
| `03-数据资产助手部署架构设计.md` | 测试 / 生产环境、核心网正式接口、大模型与可观测平台分环境对接 |
| `03-数据资产助手部署架构图.drawio` | 部署架构正式评审图 |
