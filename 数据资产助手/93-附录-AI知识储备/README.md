## 使用建议

1. 汇报主线优先看根目录的 [00-汇报思路与阅读顺序.md](../00-汇报思路与阅读顺序.md)。
2. 当被问到“为什么不全部用 Loop”“Tool 和 MCP 有什么区别”“SSE 是什么”时，再引用本目录材料。
3. 本目录内容偏方法论，不直接替代业务方案、应用架构和 Demo 实施路线。
